## 현재 개발 도구

React + TypeScript + Vite / Java 21 + Spring Boot로 구성되어 있습니다.
`/lms-test`에서 서버 `.env`의 본인 LMS 토큰으로 과목·공지·과제·마감·학습 목록을 읽기 검사할 수 있습니다.
실제 한양대 계정 데이터 반환은 별도 검증이 필요하며, 제품의 로그인·DB·AI 분석은 아직 구현하지 않았습니다.
