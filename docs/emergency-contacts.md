# 생활안내 · 긴급연락처

## 변경 범위

- `frontend/src/features/life/data/emergency-contacts.ts`: 한국 공통 긴급전화, 국가별 주한 공관 연락처, 국가 코드 조회 함수.
- `frontend/src/features/life/components/EmergencyContacts.tsx`: 프로필 국적을 읽어 표시하는 화면.
- `frontend/src/features/life/emergency-contacts.css`: 이 기능의 카드와 빨간 선택 버튼 스타일.
- 기존 `LifeGuidePage.tsx`에는 컴포넌트 import, 버튼 클래스, 준비 중 문구 교체만 적용합니다.
- 회원가입, 프로필 저장, 인증, 공통 API, 다른 게시판, 지도 코드는 변경하지 않습니다.

## 표시 규칙

1. 한국 내 소방 119 / 경찰 112 / 구급 119 카드는 국적과 관계없이 표시합니다.
2. 기존 `useDemoProfile()`에서 맞춤정보 동의와 저장된 국적을 읽습니다. 언어로 국적을 추정하지 않습니다.
3. 국가 코드가 등록되어 있으면 해당 국가의 주한 공관만 보여줍니다.
4. 국적 미입력, 동의 없음, 기존 자유입력값은 화면 내 국가 선택으로 보완합니다. 선택값은 컴포넌트 메모리에서만 사용하며 회원정보·브라우저 저장소에 쓰지 않습니다.
5. 대한민국 국적은 국내 긴급전화 안내를 표시합니다. 미등록 국가에 다른 국가 번호를 대신 보여주지 않습니다.
6. 주소록에 없는 국가·지역은 비상주 공관이나 대표부가 담당할 수 있다는 안내와 외교부 주소록 링크를 제공합니다. 주소록에 없다는 이유만으로 주한 공관이 없다고 판정하지 않습니다.
7. 공관은 등록되어 있지만 공식 주소록에 전화번호가 비어 있으면 확인 필요를 표시하며 전화 링크를 만들지 않습니다.

현재 **117개국, 131개 연락처 항목(전화번호 있는 항목 130개)**입니다.
2026-11-02 외교부 주한공관주소록 32페이지의 159개 항목 중 국제기구·기구 대표부 31개를 제외한 128개 공관을 수록했습니다.
기존 7개국 공식 안내 중 같은 전화번호 4개는 중복 제거하고 중국·일본 영사부, 태국 별도 대표전화 3개를 보완했습니다. 연락처 항목 수에는 같은 공관의 영사부 등 별도 연락 창구가 포함됩니다.
주부산필리핀총영사관은 주소록에 전화번호가 `.`으로 표시되어 번호를 생성하지 않았습니다. 같은 국가의 서울 공관 번호는 정상 표시됩니다.

서울 공관을 먼저 표시하고 부산·광주·제주 공관도 해당 국가 목록에 함께 표시합니다. 거주지별 관할지역이나 영사업무 제공 여부를 자동 판정하지 않습니다.
회원가입의 전체 국가·지역 선택지는 유지합니다. 선택지 모두가 이 주소록에 공관을 갖는 것은 아니며, 비상주 공관·대표부·명예영사 등을 모두 포괄하는 자료도 아닙니다. 예를 들어 대만(TW)은 이 주소록에서 확보하지 못해 안내 상태로 처리합니다.

## 데이터 갱신

연락처는 하나의 파일에 보관합니다. `DIRECTORY_ROWS`는 외교부 주소록의 국가 코드, 공관명, 소재지, 첫 전체 전화번호, 전화번호 원문, 외교부 수정일, 출처 페이지를 저장합니다. 국내 지역번호가 생략된 번호는 주소에 해당하는 지역번호를 보완했습니다. `/`, `~`로 축약된 나머지 번호는 임의로 확장하지 않습니다.
`SUPPLEMENTAL_CONTACTS`에는 개별 공관 공식 페이지에서 확인한 영사부·긴급 지원 번호 등을 기록합니다. `CONSULAR_CONTACTS`는 둘을 합쳐 국가별로 제공하며 같은 전화번호는 중복 제거합니다.
외교부의 한국어 국가명과 ISO 3166-1 alpha-2 코드 간 이름 차이를 대조했습니다. 특히 콩고(D.R.)는 CD, 교황청은 VA로 연결합니다.
정적 스냅샷이므로 외교부나 공관 연락처 변경 시 이 파일을 갱신해야 합니다. `verifiedAt`은 웹 자료 확인일이며 실제 통화 검증일은 아닙니다.
주한 외국공관과 해외에 있는 대한민국 공관을 구분합니다. 대표·상담 전화를 24시간 긴급전화로 표시하지 않습니다.
공식 페이지에서 별도로 확인한 경우에만 `emergencyPhone`과 이용 조건(`emergencyNote`)을 추가합니다.

## 검토 방법

자동 검증: 프론트 전체 테스트 47개(긴급연락처 신규 7개), TypeScript·Vite 빌드, Oxlint, 신규 파일 Prettier 검사 통과.
국적별 분리, 과거 입력값/미입력/주소록 미수록 국가/KR 처리, 추가 국가·지역 공관 매핑, 번호 없는 공관, 전화 링크와 공식 출처 메타데이터를 검사했습니다.
실제 브라우저 표시와 전화 앱 연결은 미검증입니다.

- 생활안내 최초 진입 시 두 선택 버튼, 긴급연락처 선택 시 빨간 선택 상태와 세 긴급전화 카드 확인.
- 국적 CN/VN/JP/US/TH/NP/IN/CA/FR 등 공관 분리, 지역 영사관, PH의 번호 없는 부산 공관, KR 국내 안내, 주소록에 없는 국가·지역 안내 확인.
- 국적 없는 프로필과 이전 자유입력 프로필에서 국가 선택, 다른 국가로 변경, 선택 해제 확인.
- 국가 선택이 회원정보에 저장되지 않는지 확인.
- 번호 링크는 기기의 전화 기능을 열도록 합니다. 검토 중 실제 긴급전화는 발신하지 않습니다.
- 서버·브라우저를 자동 실행하지 않습니다. 전화 연결과 브라우저 화면 검증은 사용자 검토 단계에서 진행합니다.
