# SCHOOL 화면 다국어

작업 브랜치: `feat/school-ui-i18n` (기준: `9102e90`, 최신 main).

## 적용 범위

- 대시보드: 인사말, 프로필 표시, 맞춤 공지 안내·분류·판별 사유·마감 표시.
- 전체공지·상세: 필터, 출처·해당 여부, 건수, 로딩·오류·번역 상태, 섹션 제목, 원문 링크, 체크 저장 안내.
- 입출국: 준비 안내, 예정 날짜의 라벨, 체크리스트, 저장·미저장·실패 안내.
- 과목알림: 과목 선택·유형 필터, 데모 암호 안내, 로딩·오류·빈 목록, 알림 종류·마감·게시일 표시.
- 학사일정·개인 저장: 탭, 건수, 월·요일·기간, 저장·삭제 버튼과 확인창, 저장 오류 안내.

기존 `LanguageProvider`의 선호 언어(한국어·영어·중국어 간체)를 그대로 사용한다. 고정 문구는 `messages.ts`에 추가하고 각 화면에서 `useLanguage().t()`로 읽는다. 화면 언어 때문에 AI나 번역 API를 추가 호출하지 않는다.

`school-message.ts`는 서버의 알려진 고정 안내·판별 사유를 현지화한다. 오류 코드와 비자 코드 등 식별자는 보존하며, 사전에 없는 서버 문구는 원문을 유지한다. 대시보드의 한국어 분류명은 기존 ‘학사’를 유지하며, 영어·중국어에서만 분류 전용 번역을 사용해 프로필 학위과정 ‘학사’와 구분한다. 공지 상세도 공통 언어 Context를 따르므로 프로필 없는 게스트의 선택 언어를 동일하게 반영한다.

## 기존 기능 유지

폴더·라우트·컴포넌트 분리 구조와 CSS는 유지한다. 백엔드·API 요청·판별 규칙·저장소·저장 키는 변경하지 않는다. 체크리스트 날짜·체크 키, 공지 필터 값, 선택 과목, 일정 제목·기간·ID의 저장값도 그대로다.

공지 제목·원문·AI 분석/번역 결과, 과목명·과제명, 학교에서 받은 일정 제목과 사용자 입력은 UI 번역 사전에 넣지 않는다. 공지 상세의 기존 콘텐츠 자동 번역은 그대로 동작하며, 실패 시 기존처럼 원문을 보여준다. 이번 변경은 목록이나 일정 제목에 새 콘텐츠 번역을 추가하지 않는다.

기존 날짜 표시 함수에는 선택적 언어 인자만 추가했다. 기본 한국어 출력은 유지하고, 다른 언어의 월·요일·날짜 표시도 동일한 한국 시간(KST)/날짜를 사용한다. 언어 변경으로 조회 기간이나 마감·진행 중 판정은 바뀌지 않는다.

## 검증

- 프론트 테스트 128개 통과: 기존 회귀 검사와 고정 문구·자리표시자 누락, 오류 코드 보존, 판별 사유, 자정·연도 경계의 날짜 현지화 검사 포함.
- `npm run build`, `npm run lint`, 변경 파일 Prettier 검사 통과.
- 저장소 밖의 임시 로컬 fixture에서 실제 화면 컴포넌트에 샘플 API 응답을 연결해 브라우저 점검. 대시보드 프로필 펼침, 영어·중국어 전환, 공지 필터/할 일 체크 유지, 번역 실패 안내·원문 보존, 입국 날짜·체크 유지와 저장, 과목 선택·유형 필터 유지, 개인 일정 저장 후 언어 전환 확인.
- 실제 Google 인증·학교 수집·LMS·Gemini 연결과 배포 환경은 이번 검증에 포함하지 않음.
