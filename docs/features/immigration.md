# 입출국 준비

코드 위치: `frontend/src/features/immigration/` (백엔드 API 없음)

#7 입출국 준비 체크리스트. 학교 하단 메뉴 "입출국"(`/entry-exit`)에서 입국 준비(`/entry-exit/entry`)나 출국 준비(`/entry-exit/exit`)를 고른다.

## 화면

- 각 화면에 예정 입국일·출국일 칸, 체크 항목 4개, 전체공지로 가는 "관련 학교 공지" 링크, "준비 진행상태 저장" 버튼이 있다.
- 체크 항목은 `checklist-store.ts`의 `CHECKLIST_ITEMS`에 있다. 입국은 여권·비자, 입국일·숙소, 학교 요청 서류, 공식 안내 원문 확인이고, 출국은 출국일·교통편, 학적·서류 처리, 기숙사·숙소 정리, 개인 조건에 맞는 공식 안내 확인이다.

## 저장

- DB 없이 계정별·입국/출국별로 localStorage(`nest:immigration-checklist:v1:<accountId>:<entry|exit>`)에 저장한다. 다른 기기와 공유되지 않는다.
- 체크하거나 날짜를 바꾸는 것만으로는 저장되지 않고 저장 버튼을 눌러야 한다. 저장하지 않은 변경이 있으면 안내한다. 공지 상세의 할 일 체크가 바로 저장되는 것과 다르다.
- 로그인하지 않으면 저장 버튼이 꺼지고 로그인 안내를 보여준다.
- 저장에 실패하면 입력한 값을 화면에 남겨 다시 시도할 수 있게 한다.
- 저장값이 손상됐거나 형식이 다른 날짜, 없는 항목 키는 빈 값으로 읽는다.

## 정한 규칙과 이유

- **날짜 칸을 직접 만들었다(#76).** 브라우저 기본 날짜 칸은 안내 글자('년-월-일')와 달력의 월·요일을 브라우저 언어로 그려서 앱 언어를 바꿔도 한국어로 남았다. 그래서 `components/DatePicker.tsx`에서 칸과 달력을 직접 그린다.
  - 빈 칸 안내와 이전 달·다음 달·오늘·지우기 문구는 `DatePicker.tsx` 안에 언어별로 둔다. 공용 `messages.ts`에는 넣지 않는다.
  - 달력 제목과 요일은 `Intl.DateTimeFormat`으로 선택 언어에 맞춘다(`calendar.ts`).
  - 날짜 계산은 UTC 기준이라 브라우저 시간대와 상관없이 같은 날짜가 나온다. "오늘"은 기기의 현재 날짜다.
  - 키보드: 화살표로 하루·한 주씩 옮기고 달 끝에서는 앞뒤 달로 넘어간다. Esc로 닫는다. Tab으로 달력 밖으로 나가거나 바깥을 누르면 닫힌다.
- **비자 안내 화면은 따로 없다.** 전체공지에서 공지를 골라 상세에서 대상·서류·할 일·원문을 본다. 프로필에 비자를 받지 않아 비자 조건이 있는 공지는 "확인 필요"가 된다([대시보드 문서](dashboard.md#정한-규칙과-이유)).
