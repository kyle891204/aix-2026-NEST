### 기존 구조 조사

- `App.tsx`: SCHOOL/LIFE 공통 헤더, 모드 선택, 하단 메뉴. 기존 `/life/*`는 준비 중 화면이었다.
- `LifeHomePage.tsx`: 자유·장터·질문 진입 카드가 모두 `/community`로 연결돼 있었다.
- `CommunityPage.tsx`: 안내 화면만 존재하며 게시글 API나 DB 모델은 없었다.
- 기존 홈의 연보라 배경, 흰 카드, LIFE 보라색 강조와 480px 앱 폭을 사용한다.

### 장터 페이지

| 경로 | 기능 |
| --- | --- |
| `/life/market` | 판매/구매 및 판매중/판매완료 필터, 건수, 카드, 글쓰기 진입 |
| `/life/market/new` | 유형·제목·가격·상태·작성 언어·내용·거래 장소 입력 |
| `/life/market/:postId` | 거래 정보·원문·작성 시간·답글 목록 및 작성 |
| `/life/market/:postId/edit` | 내 글 내용과 거래 상태 수정 |

LIFE 홈의 장터 카드와 하단 장터 메뉴가 목록에 연결된다. 기존 공통 헤더와 메뉴 디자인은 유지한다.
개발 모드에서는 기존 홈 미리보기를 장터 하위 경로까지 확장해 체험 사용자로 작성할 수 있다.
프로덕션에서는 기존 로그인 및 프로필 설정 흐름을 거친다.

### 저장과 표시

- 저장 키: `nest:market-demo:v1`. 이 탭의 모든 데모 게시글을 저장한다.
- 작성자 ID는 인증 계정 ID, 개발 미리보기는 `local-preview`다. 계정별로 내 글 수정 여부를 구분한다.
- 게시판 데이터는 같은 탭의 계정 사이에 공유되지만 다른 탭·브라우저·기기와 동기화하지 않는다.
- 각 게시판은 한국어·영어·중국어 간체 예시 글을 각각 2건씩, 총 6건 제공한다. 예시 글은 수정할 수 없다.
- 기존 저장값이 있는 탭도 글·답글을 보존하면서 누락된 외국어 예시를 ID 기준으로 추가해 읽는다. 읽는 동작만으로 저장소를 덮어쓰지 않으며, 반복 조회·저장으로 예시가 중복되지 않는다.
- 새로고침 후 복원된다. 탭 종료 시 일반적으로 사라지며 브라우저 세션 복원에 따라 남을 수 있다.
- 저장소 실패 시 저장 성공으로 처리하지 않는다. 손상된 데이터는 자동 덮어쓰지 않고 오류를 표시한다.
- 작성자 구분은 데모 UI 동작이며 서버 권한 보장이 아니다.
- 작성 원문과 작성 언어를 보관하고, 공통 게시판 번역 기능으로 조회자의 선호 언어 번역을 표시한다.
- 사진 업로드·채팅·결제·글 삭제는 이번 범위에 포함하지 않는다.

### 2026-10-30 답글 수정·삭제

답글 작성자에게만 수정·삭제 버튼을 표시한다. 수정은 인라인 입력 후 저장/취소,
삭제는 확인/취소를 거친다. 변경 함수도 답글 작성자 ID를 검사하며 게시글 작성자는
타인이 쓴 답글을 관리할 수 없다. 저장 실패 시 수정 입력을 유지한다.
개발 미리보기는 모든 비로그인 사용자가 같은 `local-preview` ID를 사용하므로
다른 실제 사용자 구분은 로그인 계정으로 확인해야 한다.

### 질문 해결·삭제 규칙 (2026-10-30)

- 본인의 미해결 질문: 답글 0개면 삭제 가능·해결 불가, 1개 이상이면 삭제 불가·해결 가능. 수정은 가능.
- 해결은 상세 화면에서 선호 언어(ko/en/zh)의 고정 문구와 확인/취소를 거친다. Gemini는 사용하지 않는다.
- 해결된 질문은 수정·삭제·미해결 전환 불가. 답글이 나중에 모두 삭제돼도 잠금은 유지된다.
- 새 질문은 항상 미해결이며 작성·수정 폼에서 상태를 직접 선택할 수 없다. 직접 수정 URL 접근도 차단한다.
- 기존 답글 작성자 권한은 유지한다. 전체 자동 테스트 18개, 빌드·lint 통과. 브라우저 시각 검증은 미실행.

#### 해결된 질문의 답글 잠금

해결된 질문에 달린 답글은 작성자도 수정·삭제할 수 없다. 화면의 버튼을 숨기고
`updateQuestionReply`에서도 질문 상태를 검사한다. 미해결 질문의 본인 답글 수정·삭제는 유지한다.
저장 복원 후에도 잠금이 유지되는 자동 테스트를 확인했다.

## 자유게시판

기존 장터·질문게시판 흐름을 참고한 자유게시판 기본 구현이다. React Context와
`sessionStorage`를 사용하며 DB·게시글 저장 API는 사용하지 않는다.

### 파일 구조

코드 위치: `frontend/src/features/free-board/`

- `free-board-store.ts`: 글·댓글 타입, 예시 글, 저장·복원, 입력 검증 및 작성자 검사
- `free-board-context.ts`: Context와 `useFreeBoard` 훅
- `pages/FreeBoardLayout.tsx`: 로그인·프로필의 작성자 정보 연결, 탭 저장 및 저장 실패 처리
- `pages/FreeBoardPages.tsx`: 목록, 상세, 작성·수정 화면
- `components/FreeBoardReplyCard.tsx`: 댓글 표시와 본인 댓글 수정·삭제
- `free-board.css`: 자유게시판 전용 스타일. 기존 `market.css`는 import만 한다.

장터(`market/`)·질문게시판(`questions/`)도 같은 구성이다. `market-context.ts`·`question-context.ts`,
`pages/MarketLayout.tsx`·`pages/QuestionLayout.tsx`, `pages/MarketPages.tsx`·`pages/QuestionPages.tsx`,
`components/MarketReplyCard.tsx`·`components/QuestionReplyCard.tsx`로 나뉜다.

날짜 표시는 공통 `shared/i18n/language.ts`의 `formatBoardDate`를 사용한다.
표시 언어는 선호 언어를 따르고 시간대는 한국 시간(`Asia/Seoul`)을 유지한다.

### 동작 기준

- 글 목록·상세 조회, 글 작성·수정·삭제, 댓글 작성·수정·삭제를 제공한다.
- 글 작성자만 글을 수정·삭제한다. 댓글이 있어도 글을 삭제할 수 있고 댓글도 함께 제거된다.
- 댓글은 해당 댓글 작성자만 수정·삭제한다. 글 작성자가 타인의 댓글을 개별 삭제할 수는 없다.
- 해결·미해결 상태와 수정 잠금은 없다.
- 제목은 80자, 본문은 3,000자, 댓글은 1,000자까지 입력한다.
- 원문과 작성 언어를 보관하고 기존 공통 게시판 번역 기능으로 표시한다.
- 한국어·영어·중국어 각 2건의 예시 글은 읽기 전용이며 댓글을 달 수 있다.
- 예시 글마다 목업 댓글이 1~2개씩 있으며 게시판 전체에서 한국어·영어·중국어 간체를 고르게 시연한다. 기존 탭의 예전 3개짜리 목업도 현재 구성으로 줄이고 사용자 글·댓글은 보존한다.
- 한국어 예시 글 작성자는 송선우·김용태다.
- 글은 등록 순서대로 최신 글이 위에 놓인다. 수정해도 작성 시각과 댓글을 유지한다.
- 저장 키는 `nest:free-board-demo:v1`이며 장터·질문·프로필 저장소와 분리한다.
- 저장 실패 시 화면 상태를 성공으로 바꾸지 않고 입력을 유지한다.
- 손상된 저장 데이터는 오류를 표시하고 쓰기를 막아 기존 데이터를 덮어쓰지 않는다.
- 작성자는 기존 `session.user.id`, 표시 이름·언어는 저장 프로필을 따른다.
- 개발 미리보기는 기존 게시판과 같은 `local-preview` ID를 사용한다.
- 같은 탭의 로그인 계정들은 같은 게시글 목록을 보며, 작성자 ID로 관리 가능 여부를 구분한다.

### 화면 연결

사용자 승인에 따라 `App.tsx`에 아래 라우트와 개발 미리보기 경로를 연결하고,
`LifeHomePage.tsx`의 자유게시판 링크를 `/life/free`로 통일했다.
기존 장터·질문게시판 기능 코드는 변경하지 않는다.

`App.tsx`에서 아래 컴포넌트를 import한다.

```tsx
import {
  FreeBoardLayout,
  FreeBoardListPage,
  FreeBoardDetailPage,
  FreeBoardFormPage,
} from '../features/free-board/pages/FreeBoardPages'
```

`ProtectedApp` 하위에 자유게시판 라우트를 추가한다.

```tsx
<Route path="/life/free" element={<FreeBoardLayout />}>
  <Route index element={<FreeBoardListPage />} />
  <Route path="new" element={<FreeBoardFormPage />} />
  <Route path=":postId" element={<FreeBoardDetailPage />} />
  <Route path=":postId/edit" element={<FreeBoardFormPage />} />
</Route>
```

개발 미리보기 경로 조건에 `location.pathname.startsWith('/life/free/')`를 추가한다.
`LifeHomePage.tsx`의 자유게시판 링크는 `/community`에서 `/life/free`로 연결한다.

### 확인 방법

`frontend`에서 `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`를 실행한다.
자유게시판 테스트는 `frontend/tests/free-board.test.ts`에 있다.

자동 테스트 33개(자유게시판 6개 포함), 타입 검사·빌드·lint 및 변경 파일 포맷 검사를 통과했다.
브라우저에서 LIFE 홈 → 자유게시판 이동, 글·댓글 작성, 새로고침 후 복원,
댓글이 있는 글 수정, 댓글 수정, 글 삭제 확인 및 취소를 확인했다.
댓글이 있는 글의 실제 삭제·작성자별 권한·저장 실패는 자동 테스트로 검증했다.
