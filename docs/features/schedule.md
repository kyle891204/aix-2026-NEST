# 학사일정

코드 위치: `frontend/src/features/schedule/`

#10 학사일정. `GET /api/v1/schedules/academic`으로 이번 달부터 학년도 끝(2월)까지의 학부 학사일정을 받아 월별로 보여준다.

개인 일정은 서버 API 없이 계정별 localStorage에 저장한다(`personal-schedule-store.ts`). 학사일정을 저장하고 삭제할 수 있다.
같은 브라우저의 다른 탭에서 저장한 일정을 덮어쓰지 않도록 저장 직전에 다시 읽고, `storage` 이벤트로 다른 탭의 변경을 반영한다.

학사일정 데이터 갱신 방법은 [API 계약](../api.md#get-apiv1schedulesacademic)의 "일정 갱신"을 참고한다.

## 정한 규칙과 이유

개인 일정에 저장하는 곳은 세 군데다.

| 저장하는 곳 | 방법 | 저장할 수 없는 경우 |
| --- | --- | --- |
| 학사일정 "학교 학사일정" 탭 | 일정마다 저장 버튼 | 이미 끝난 일정(버튼을 보여주지 않음) |
| 과목알림 과목별 화면 (`courses/CourseNoticesPage.tsx`) | 공지·과제를 체크박스로 여러 개 골라 저장 | 마감이 지났거나 마감일이 없는 항목(체크박스 없음) |
| 공지 상세 (`notices/pages/NoticeDetailPage.tsx`) | 본문에서 마감일을 찾은 공지만 저장 버튼 활성 | 마감일 없음, 마감 지남, 예시 공지, 비로그인(버튼에 이유 표시) |

- 과목알림·공지 상세에서 저장하면 "개인 저장" 탭으로 이동해 방금 저장한 일정을 알려준다. 학사일정 탭에서는 그 자리에 머문다.
- 같은 일정은 두 번 저장하지 않는다. 이미 저장한 항목은 "저장됨"으로 표시한다.
- 개인 저장 탭에서 삭제할 수 있다. 저장한 일정은 계정별로 이 브라우저에만 남고 다른 기기와 공유되지 않는다.

화면에서 직접 fetch하지 않고 `shared/api/client.ts`를 통해 요청한다. 아직 없는 API는 구현 완료처럼 표시하지 않는다.
