# 과목알림

코드 위치: `frontend/src/features/courses/`, 백엔드 `course/` (LMS 호출은 `integrations/lms`, 개발 검사 도구는 [lms.md](lms.md))

#9. 한양대 LMS(Canvas)의 과목·공지·과제·학습자료를 모아 보여준다. 전체 과목(S08), 과목별(S09), 공지·과제 상세 화면이 있다.

## 정한 규칙과 이유

- 모든 접속자가 서버에 설정한 **공통 데모 계정 하나**의 LMS 데이터를 본다. 사용자별 수강 여부는 판별하지 않는다. 그래서 운영에서는 `lms-demo` 프로필일 때만 API를 열고 데모 암호로 보호한다([배포 설정](../deployment.md#공통-계정-lms-데모)). 로그인도 필요하다.
- 공지 조회 기간 기본값은 한국 날짜 기준 최근 90일이다. 종료일만 보내면 그 전 90일, 시작일만 보내면 오늘까지다. 과목별 화면의 과제는 기간과 관계없이 모두 가져온다.
- 과제 마감은 LMS가 사용자에게 적용한 값을 그대로 쓰고 다시 추정하지 않는다.
- LMS 공지에는 마감일 칸이 없어, 본문의 "11/20(금) 23:59까지 제출", "~ 2026.11.20 마감" 같은 문구에서 **규칙으로** 마감을 찾는다(`AnnouncementDeadlines`, AI 아님).
  - 날짜 바로 뒤에 까지·마감·제출·due가 오거나, 바로 앞에 ~·마감·기한·deadline이 있어야 마감으로 본다.
  - 연도가 없으면 게시한 해로 본다(연말 공지의 연초 날짜는 다음 해). 시각이 없으면 23:59다.
  - 못 찾으면 "마감 확인 필요"와 원문 확인을 안내한다.
- 전체 과목 화면은 마감 전(임박순) → 마감 없는 공지(최근 게시순) → 마감 지난 공지·과제(최근 마감순)로 둔다. 마감 지난 항목은 접어 두고 버튼으로 펼친다. 학습자료와 마감 없는 과제는 과목별 화면에서만 본다.
- 한 과목·한 유형이 실패해도 나머지는 보여주고 실패한 것만 따로 안내한다. 모두 실패하면 LMS 오류를 그대로 돌려준다. LMS 부담을 줄이려고 동시에 4과목까지만 조회한다.
- 과목별 화면에서 마감이 남은 공지·과제를 골라 [개인 일정](schedule.md)에 저장한다.
- 공지 본문·과제 설명 HTML은 실행하지 않고, 줄바꿈만 살린 글로 바꿔 보여준다.

API: `GET /api/v1/courses`, `GET /courses/notifications`, `GET /courses/{courseId}/notifications?type=ALL|ANNOUNCEMENT|ASSIGNMENT|MATERIAL&startDate=&endDate=`. [API 계약](../api.md)에는 아직 없다.
