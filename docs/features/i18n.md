# 화면 다국어 (고정 UI 문구)

## 로그인·회원가입·LIFE 화면 다국어

### 적용 범위

- 로그인: Google 로그인 버튼 바로 아래 한국어 / English / 中文 선택 버튼, 안내·개인정보 문구, Google 버튼 언어와 오류 안내.
- 회원가입: 동의, 프로필 입력, 학교·단과대학·학과·국적·과정·학년의 표시 문구.
- 계정: 선호 언어 즉시 변경, 프로필·동의 수정 시 언어 미리보기.
- LIFE: 홈, 자유·장터·질문 게시판의 목록·상세·작성·수정·답글·확인창, 생활안내·지도 상태·긴급연락처.
- 공통: 헤더, 계정 링크, 하단 메뉴, 문서 언어와 브라우저 탭 제목.

초기 작업에서는 SCHOOL 개별 기능 화면을 제외했으며, 후속 적용 범위는 아래 [SCHOOL 화면 다국어](#school-화면-다국어)에 기록한다.

### 동작과 저장

1. 로그인 전 선택은 `nest:ui-language:v1`에 탭 세션 단위로 저장한다. 기본값은 한국어다.
2. 신규 회원은 선택한 언어로 동의 화면과 프로필 화면을 보고, 선호 언어 기본값도 해당 언어를 사용한다.
3. 기존 계정은 `nest:demo-profile:v1:<accountId>`에 저장된 선호 언어를 우선한다.
4. 회원가입·프로필 수정 중 언어를 바꾸면 현재 입력값을 보존하고 화면을 즉시 전환한다. 기존 계정의 저장된 프로필은 제출하기 전까지 변경하지 않는다.
5. 내 계정의 언어 버튼은 기존 프로필의 나머지 필드를 보존해 저장하고, 성공한 경우 화면을 즉시 전환한다. 저장 실패 시 기존 언어를 유지하고 안내한다.
6. 프로필 저장 방식은 기존과 같은 `sessionStorage`다. 서버나 다른 기기와 동기화하지 않는다.

### 구현

`frontend/src/shared/i18n/messages.ts`의 고정 UI 문구를 `useLanguage().t()`로 읽는다. 한국어 원문을 카탈로그 키로 사용하며 영어·중국어(간체) 값을 미리 제공한다. 숫자 등을 포함하는 문장은 `{count}` 같은 이름 있는 자리를 사용한다. 알 수 없는 문구는 원문으로 유지한다.

화면 문구에는 번역 API, AI, 네트워크 요청을 사용하지 않는다. 기존 공지·게시글·답글 자동 번역은 콘텐츠 전용 기능으로 유지한다. 게시글의 원문과 작성 언어는 UI 언어와 별도로 보존한다.

학교·단과대학 ID, 학과·과정·학년의 저장값, 국가 코드는 변경하지 않고 표시 이름만 현지화한다. 국가명은 `Intl.DisplayNames`, 게시판 날짜는 해당 언어의 `Intl.DateTimeFormat`을 사용하며 시간대는 `Asia/Seoul`을 유지한다.

### 확인

- `npm test`: 카탈로그 누락·자리표시자 일치, 언어 초기화·저장·손상값 처리, 프로필 저장값 보존, 국가·학과 표시, 한국 시간 유지 및 기존 기능 회귀 테스트.
- `npm run build`, `npm run lint`.
- 별도 로컬 인증 fixture로 로그인 언어 → 가입 동의·프로필 → 선호 언어 저장 → LIFE 반영을 브라우저에서 확인. 실제 Google 로그인이나 외부 번역 서비스는 호출하지 않음.
- 중국어 가입에서 영어로 전환해도 이름·학교·학과·국적·과정·학년 값 유지 확인.
- 저장 전 프로필 언어 변경을 취소하면 기존 선호 언어 유지, 내 계정에서 변경 후 새로고침하면 선택 유지 확인.

## SCHOOL 화면 다국어

### 적용 범위

- 대시보드: 인사말, 프로필 표시, 맞춤 공지 안내·분류·판별 사유·마감 표시.
- 전체공지·상세: 필터, 출처·해당 여부, 건수, 로딩·오류·번역 상태, 섹션 제목, 원문 링크, 체크 저장 안내.
- 입출국: 준비 안내, 예정 날짜의 라벨, 체크리스트, 저장·미저장·실패 안내.
- 과목알림: 전체 과목(S08) 과목 카드·탭·요약, 과목별(S09) 유형 탭·선택 저장, 공지·과제 상세(S09-N·S09-T), 데모 암호 안내, 로딩·오류·빈 목록, 알림 종류·마감·게시일 표시.
- 학사일정·개인 저장: 탭, 건수, 월·요일·기간, 저장·삭제 버튼과 확인창, 저장 오류 안내.

기존 `LanguageProvider`의 선호 언어(한국어·영어·중국어 간체)를 그대로 사용한다. 고정 문구는 `messages.ts`에 추가하고 각 화면에서 `useLanguage().t()`로 읽는다. 화면 언어 때문에 AI나 번역 API를 추가 호출하지 않는다.

`school-message.ts`는 서버의 알려진 고정 안내·판별 사유를 현지화한다. 오류 코드와 비자 코드 등 식별자는 보존하며, 사전에 없는 서버 문구는 원문을 유지한다. 대시보드의 한국어 분류명은 기존 ‘학사’를 유지하며, 영어·중국어에서만 분류 전용 번역을 사용해 프로필 학위과정 ‘학사’와 구분한다. 공지 상세도 공통 언어 Context를 따르므로 프로필 없는 게스트의 선택 언어를 동일하게 반영한다.

### 기존 기능 유지

폴더·라우트·컴포넌트 분리 구조와 CSS는 유지한다. 백엔드·API 요청·판별 규칙·저장소·저장 키는 변경하지 않는다. 체크리스트 날짜·체크 키, 공지 필터 값, 선택 과목, 일정 제목·기간·ID의 저장값도 그대로다.

공지 제목·원문·AI 분석/번역 결과, 과목명·과제명, 학교에서 받은 일정 제목과 사용자 입력은 UI 번역 사전에 넣지 않는다. 공지 상세의 기존 콘텐츠 자동 번역은 그대로 동작하며, 실패 시 기존처럼 원문을 보여준다. 이번 변경은 목록이나 일정 제목에 새 콘텐츠 번역을 추가하지 않는다.

기존 날짜 표시 함수에는 선택적 언어 인자만 추가했다. 기본 한국어 출력은 유지하고, 다른 언어의 월·요일·날짜 표시도 동일한 한국 시간(KST)/날짜를 사용한다. 언어 변경으로 조회 기간이나 마감·진행 중 판정은 바뀌지 않는다.

### 검증

- 프론트 테스트 128개 통과: 기존 회귀 검사와 고정 문구·자리표시자 누락, 오류 코드 보존, 판별 사유, 자정·연도 경계의 날짜 현지화 검사 포함.
- `npm run build`, `npm run lint`, 변경 파일 Prettier 검사 통과.
- 저장소 밖의 임시 로컬 fixture에서 실제 화면 컴포넌트에 샘플 API 응답을 연결해 브라우저 점검. 대시보드 프로필 펼침, 영어·중국어 전환, 공지 필터/할 일 체크 유지, 번역 실패 안내·원문 보존, 입국 날짜·체크 유지와 저장, 과목 선택·유형 필터 유지, 개인 일정 저장 후 언어 전환 확인.
- 실제 Google 인증·학교 수집·LMS·Gemini 연결과 배포 환경은 이번 검증에 포함하지 않음.
