# 로그인·회원가입·LIFE 화면 다국어

작업 브랜치: `feat/auth-life-i18n`

## 적용 범위

- 로그인: Google 로그인 버튼 바로 아래 한국어 / English / 中文 선택 버튼, 안내·개인정보 문구, Google 버튼 언어와 오류 안내.
- 회원가입: 동의, 프로필 입력, 학교·단과대학·학과·국적·과정·학년의 표시 문구.
- 계정: 선호 언어 즉시 변경, 프로필·동의 수정 시 언어 미리보기.
- LIFE: 홈, 자유·장터·질문 게시판의 목록·상세·작성·수정·답글·확인창, 생활안내·지도 상태·긴급연락처.
- 공통: 헤더, 계정 링크, 하단 메뉴, 문서 언어와 브라우저 탭 제목.

초기 작업에서는 SCHOOL 개별 기능 화면을 제외했으며, 후속 적용 범위는 [SCHOOL 화면 다국어](i18n-school.md)에 기록한다.

## 동작과 저장

1. 로그인 전 선택은 `nest:ui-language:v1`에 탭 세션 단위로 저장한다. 기본값은 한국어다.
2. 신규 회원은 선택한 언어로 동의 화면과 프로필 화면을 보고, 선호 언어 기본값도 해당 언어를 사용한다.
3. 기존 계정은 `nest:demo-profile:v1:<accountId>`에 저장된 선호 언어를 우선한다.
4. 회원가입·프로필 수정 중 언어를 바꾸면 현재 입력값을 보존하고 화면을 즉시 전환한다. 기존 계정의 저장된 프로필은 제출하기 전까지 변경하지 않는다.
5. 내 계정의 언어 버튼은 기존 프로필의 나머지 필드를 보존해 저장하고, 성공한 경우 화면을 즉시 전환한다. 저장 실패 시 기존 언어를 유지하고 안내한다.
6. 프로필 저장 방식은 기존과 같은 `sessionStorage`다. 서버나 다른 기기와 동기화하지 않는다.

## 구현

`frontend/src/shared/i18n/messages.ts`의 고정 UI 문구를 `useLanguage().t()`로 읽는다. 한국어 원문을 카탈로그 키로 사용하며 영어·중국어(간체) 값을 미리 제공한다. 숫자 등을 포함하는 문장은 `{count}` 같은 이름 있는 자리를 사용한다. 알 수 없는 문구는 원문으로 유지한다.

화면 문구에는 번역 API, AI, 네트워크 요청을 사용하지 않는다. 기존 공지·게시글·답글 자동 번역은 콘텐츠 전용 기능으로 유지한다. 게시글의 원문과 작성 언어는 UI 언어와 별도로 보존한다.

학교·단과대학 ID, 학과·과정·학년의 저장값, 국가 코드는 변경하지 않고 표시 이름만 현지화한다. 국가명은 `Intl.DisplayNames`, 게시판 날짜는 해당 언어의 `Intl.DateTimeFormat`을 사용하며 시간대는 `Asia/Seoul`을 유지한다.

## 확인

- `npm test`: 카탈로그 누락·자리표시자 일치, 언어 초기화·저장·손상값 처리, 프로필 저장값 보존, 국가·학과 표시, 한국 시간 유지 및 기존 기능 회귀 테스트.
- `npm run build`, `npm run lint`.
- 별도 로컬 인증 fixture로 로그인 언어 → 가입 동의·프로필 → 선호 언어 저장 → LIFE 반영을 브라우저에서 확인. 실제 Google 로그인이나 외부 번역 서비스는 호출하지 않음.
- 중국어 가입에서 영어로 전환해도 이름·학교·학과·국적·과정·학년 값 유지 확인.
- 저장 전 프로필 언어 변경을 취소하면 기존 선호 언어 유지, 내 계정에서 변경 후 새로고침하면 선택 유지 확인.
