## 표시 규칙

1. 보기 방식은 두 가지입니다.
   - **주요 시설 (기본):** 직접 확인한 15곳. 운영시간까지 보여주고, 모든 마커가 보이게 지도를 맞춥니다.
   - **주변 전체:** 지금 지도 범위 안의 시설을 카카오 장소 검색으로 바로 찾습니다. 지도를 움직이거나 확대하면 멈춘 뒤 0.3초 후 다시 검색합니다. 가까운 마커는 숫자 묶음으로 보이고, 묶음을 누르면 확대됩니다.
2. 필터는 **전체·병원·마트·약국**입니다. 이슈 #15의 "지역 선택"은 팀 합의로 이번 범위에서 뺐습니다. 현재 위치(GPS) 기반 검색도 넣지 않았습니다(2026-11-11 결정). 다른 지역은 "주변 전체"에서 지도를 직접 옮겨 찾습니다.
3. 목록은 캠퍼스 중심에서의 **직선거리** 순입니다. 길찾기 거리가 아닙니다. 20곳씩 보여주고 "더 보기"로 늘립니다.
4. 마커나 목록 항목을 누르면 지도가 그 시설로 이동하고, 지도 아래에 상세가 열리며 그 위치로 스크롤됩니다. 보기 방식이나 필터를 바꾸면 선택이 해제됩니다.
5. 지도를 불러오지 못해도 주요 시설의 목록과 상세는 그대로 쓸 수 있습니다. 주변 전체는 지도가 있어야 검색되므로, 지도가 없으면 그 안내를 보여줍니다. 검색이 실패하면 오류 안내와 "다시 시도" 버튼을 보여줍니다.
6. 업체 이름과 주소는 번역하지 않고 원문을 보여줍니다. 택시나 길찾기에 그대로 쓸 수 있게 하기 위해서입니다. 분류·요일·안내 문구는 선호 언어로 표시합니다. 주변 전체에서 사전에 없는 카카오 분류는 한국어 원문 그대로 보입니다.
7. 운영시간은 연속된 요일의 시간이 같으면 `월~금`처럼 묶습니다. 휴무(`null`)와 정보 없음(키 없음)을 구분합니다.
8. 화면 하단에 확인일과 "운영시간·연락처는 바뀔 수 있음" 안내를 표시하고, 상세에는 카카오맵 원본 링크를 둡니다.

## 주변 전체 보기

- **검색:** 카카오 지도 JavaScript SDK의 `services.Places.categorySearch`로 병원 `HP8`·마트 `MT1`·약국 `PM9`를 지도 범위(`bounds`) 안에서 찾습니다. 지도 중심에서 가까운 순입니다. 키는 지도와 같은 `VITE_KAKAO_MAP_JS_KEY`라 서버 작업이나 REST 키가 필요 없습니다.
- **개수 제한:** 카카오는 검색 한 번에 유형별 최대 45곳(15곳 × 3페이지)만 줍니다. SDK는 전체 개수도 45로 잘라서 주므로, 45곳을 꽉 채워 받으면 "지도를 확대하면 더 볼 수 있다"는 안내를 띄웁니다. 참고로 REST API 기준 캠퍼스 반경 2km 안에 병원 128곳·마트 8곳·약국 45곳, 3km 안에 병원 443곳·마트 14곳·약국 151곳이 있습니다(2026-11-11 조회).
- **표시 규칙:**
  - 병원 그룹(HP8)에 섞여 나오는 **동물병원**(`가정,생활 > 반려동물 > 동물병원`)은 뺍니다. 나머지 진료과(치과·한의원·피부과 등)는 모두 표시하고 진료과 이름을 분류로 보여줍니다.
  - 마트는 `대형마트`·`슈퍼마켓` 중 하나로 표시합니다.
  - 검색 결과가 주요 시설 15곳 중 하나면, 확인한 운영시간이 있는 주요 시설 데이터를 그대로 씁니다. 나머지 시설의 운영시간 칸에는 "카카오맵에서 확인해 주세요."를 보여줍니다. 장소 검색 API는 운영시간을 주지 않습니다.
- **요청량:** 지도가 멈춘 뒤에만 검색하고, 같은 범위는 다시 검색하지 않습니다. 한 번 검색할 때 전체 필터는 최대 9번(3유형 × 3페이지), 유형 하나는 최대 3번 요청합니다.

## 출처와 갱신 방법

- **이름·주소·전화·좌표:** 카카오 로컬 API(`/v2/local/search/category.json`, `keyword.json`)를 ERICA 중심 거리순으로 검색한 결과를 그대로 옮겼습니다. `id`는 카카오맵 장소 ID이며, 원본 링크 `https://place.map.kakao.com/{id}`를 만들 때 씁니다.
- **운영시간:** 각 카카오맵 장소 페이지의 "영업정보"에 표시된 확인일 기준 7일치를 요일별로 옮겼습니다. 날짜별 임시 변경이 섞여 있을 수 있습니다. 예를 들어 우리들가족의원은 수요일만 14:00부터이고, 더베스트내과는 월요일이 오전만이며 일요일 정보가 없습니다. 이런 값은 보정하지 않고 표시된 그대로 두었습니다.
- **마트 의무휴업:** 카카오맵에는 일요일 휴무가 보이지만, 안산시가 의무휴업일을 평일로 바꿨다는 보도도 있어 요일을 특정하지 않았습니다. 대신 "월 2회 의무휴업일이 있습니다" 안내만 표시합니다.
- **노브랜드 전화번호:** 두 매장 모두 카카오맵에 본사 대표번호(02-380-5111)로 등록되어 있어 그대로 두었습니다.
- **갱신할 때:**
  1. 같은 API로 이름·주소·전화·좌표를 다시 조회합니다.
  2. 장소 페이지에서 운영시간을 다시 확인합니다.
  3. `NEARBY_FACILITIES_SOURCE.verifiedAt`을 새 확인일로 바꿉니다.
  4. 분류(`category`)를 새로 추가했다면 `messages.ts`에 번역을 추가합니다. 테스트가 누락을 잡아냅니다.

## 로컬 실행 시 카카오 키

- 지도는 `frontend/.env`의 `VITE_KAKAO_MAP_JS_KEY`를 씁니다. 이 키는 카카오 개발자 콘솔의 **앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인**에 등록된 도메인에서만 동작합니다.
- 로컬은 `http://localhost:5173`으로 접속해야 합니다. `127.0.0.1`은 등록 상태에 따라 거부될 수 있습니다.
- 데이터를 다시 조회할 때 쓰는 REST 키는 브라우저에 노출되지 않도록 `VITE_` 접두사 없이 둡니다.
- `.env`는 git이 무시하는 파일입니다. 절대 커밋하지 않습니다.
